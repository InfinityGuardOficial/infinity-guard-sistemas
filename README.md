# Mídia da Infinity Guard (branch `midia`)

Usado pelas rotinas na nuvem para criar e publicar os Reels sem depender do PC do dono.

- `acervo/loja/<id do produto>/` — fotos da página do produto no site (capas sem texto em inglês).
- `acervo/proprio/<produto>/` — fotos do próprio dono.
- `acervo/marca/` — logo e imagens de marca.
- `ferramentas/gerar-video.sh` — gera o Reel 9:16 a partir de um `roteiro.txt`.
- `videos/` — Reels prontos (link público em raw.githubusercontent.com/.../midia/videos/<arquivo>.mp4), publicados pelo Metricool.

Nada aqui é de terceiros.
