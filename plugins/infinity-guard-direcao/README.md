# infinity-guard-direcao · 2.3.0

Squad Direção: o diretor-geral, que decide as prioridades da semana e divide as metas entre os squads.

- Funcionários: `diretor-geral`
- Skills: `atendente-infinity-guard`, `campanha-sazonal`, `conteudo-semanal`, `monitor-de-gestao`, `painel-de-vendas`, `prova-da-loja`, `radar-de-concorrentes`, `reuniao-semanal`, `revisor-de-promessas`, `suporte-tecnico`

Instalar:
```
/plugin marketplace add InfinityGuardOficial/infinity-guard-sistemas
/plugin install infinity-guard-direcao@infinity-guard-sistemas
```

Gerado por `scripts/gerar-plugins.py` a partir de `agents/` e `skills/` da raiz: edite lá, não aqui.
